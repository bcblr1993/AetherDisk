日期：2026-10-25（Asia/Shanghai）。版本 0.2.2，构建 2026102502，Apple Silicon、macOS 14+。

## 本版改动

已确认的 UI 改版转为正式构建：按钮共用主操作、次操作、文字操作与红色危险操作样式，统一高度、圆角、焦点和深浅色；搜索框与卡片共用组件。清理确认、未读取路径面板采用同一标题、内容和底部操作栏，保留源码、安装包保护及风险提示。设置页适应窗口宽度。系统文件和 CSV 保存面板依附当前窗口，防止重复打开，取消后恢复操作状态。

清理仍仅在用户确认并重新校验后移入系统废纸篓，禁止永久删除或自动清空。此版未修改扫描与清理核心规则。

## 验收边界

运行验收为 Apple Silicon 本机及 macos27 VM，不等于逐一实测 macOS 14–26 或完整 VoiceOver 矩阵。扫描是动态文件系统观测，不是原子快照；APFS 共享数据不等于可释放空间。保护依赖规则与用户设置，重要文件仍应备份并逐项核对。

测试只写入与清理本次新建的专用夹具；废纸篓只恢复本次测试条目。旧正式安装包与源码保留。0.2.1 验收记录保存在 VERIFICATION-0.2.1.md。
