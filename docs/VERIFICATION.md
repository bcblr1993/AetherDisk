# 0.2.1 扫描准确性与清理安全复核

版本 0.2.1，最终构建 2026102409，日期 2026-10-24。

## 发现并修复

- 路径被替换成链接时，原路径式目录枚举可能跟随新链接。现在根目录与各层目录均以 `O_NOFOLLOW` 打开，使用 `fstatat(AT_SYMLINK_NOFOLLOW)` 和目录句柄枚举，核对设备与 inode。
- 仅凭名称识别 `.gradle`、`.dart_tool`、`DerivedData` 过于宽泛。现在要求对应的真实项目文件；目录或链接不能充当项目文件。
- 补齐 JSX、Kotlin 脚本、PHP、构建脚本等源码，以及 tgz/xip/iso/ipsw/aar/bin/run 等安装包与发布归档保护。无扩展名可执行文件保守保护。Git 裸仓库、其他版本控制标记和源码/发布容器内部缓存也受保护。
- Git 只检查已跟踪文件会遗漏未忽略的未知类型源码，且错误原先可能被当作无跟踪文件。现在已跟踪或未被忽略的文件均阻止清理，校验失败保留文件；清除继承的 Git 环境覆盖，禁用 fsmonitor。
- 最后一次占用检查后新增文件原先没有再次复核。现在占用检查在前、完整内容复核紧邻废纸篓操作；指纹包含 ctime、硬链接数及块数，并使用结构化编码避免文件名分隔符歧义。
- 预览对同一硬链接重复计算，现与扫描一致去重；规范化路径后去重与检查父子重叠。失败后报告全部未处理项目。
- 扫描纳入链接自身块数，跨卷、深度限制及遍历期间目录变化明确标记部分结果。最后进度保留顶层条目；部分扫描不覆盖完整历史。
- 清理检查期间禁止切换扫描，确认入口再次检查状态。
- 按用户要求，在清理确认页、设置页及官网 FAQ/下载提示加入备份、误判风险与责任说明。免责声明不替代保护校验。

## 验证边界

扫描读取元数据，统计不是原子快照；APFS 克隆共享不等于可释放空间。目录排行为有限样本，类型汇总遍历全部已读唯一文件。

保护依赖规则与用户设置，无法识别刻意伪装成缓存、任意重命名或未知用途的全部数据。进程占用检查与最后复核降低竞争风险，但不能把不配合协调的并发文件系统操作变成原子事务。重要源码和正式安装包建议额外保护整个目录。仅确认后移入废纸篓，永不永久删除或清空废纸篓。

所有有写入或清理的测试均使用临时测试路径或专用 macos27 夹具。实际废纸篓条目只恢复本次测试条目，未操作用户项目、安装包或聊天数据。
