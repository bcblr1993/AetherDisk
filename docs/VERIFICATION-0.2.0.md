# 0.2.0 发布验收记录

日期：2026-10-24（Asia/Shanghai）。版本 **0.2.0 / 2026102405**，Apple Silicon、macOS 14+ 部署目标。

## 本版补齐的核心功能

1. 跨目录大文件排行：名称/路径搜索、类型和大小筛选；区分磁盘占用和逻辑大小。至少 1 MiB，按两种大小分别保留前 200 项、合并最多 400 项；只查看和 Finder 定位。
2. 文件类型占用：基于扩展名归类，不读取内容；统计全部已读唯一文件，目录显示预算不影响汇总，硬链接去重。
3. 自定义保护目录：本机保存，继续统计，阻止清理它、内部内容及包含它的缓存父目录。预览和执行均再次校验。移除自定义保护不会移除源码、安装包等内置保护。
4. 原生 CSV 导出与权限详情：默认保存至文稿，支持取消。CSV 使用 UTF-8 BOM、引号转义与公式防护，包含扫描状态、大小、类型汇总、保留的节点与未读取路径；不是所有文件的完整清单。最多显示前 50 条未读取路径。
5. 报告、常见文档默认保护；切换目录清除旧搜索；设置窗口可滚动。
