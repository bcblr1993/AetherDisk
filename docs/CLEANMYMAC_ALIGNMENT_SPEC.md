# AetherDisk × CleanMyMac 1:1 深度对齐架构与设计总规范

## 一、核心对齐原则与安全底线

本规范以 **MacPaw CleanMyMac（CleanMyMac 5 现代界面体系）** 为 1:1 视觉与交互标杆，消除传统后台仪表盘式的卡片堆叠感，实现真正的**全画布沉浸式舞台 + 悬浮毛玻璃侧栏 + 居中悬浮发光主控圆球 + 七大官方对标模块**，同时严格遵守 `AGENTS.md` 全部工程红线：

1. **生产依赖唯一**：Swift 6 + SwiftUI + AppKit 原生实现，唯一外部生产依赖保持 `Sparkle 2.10.0`。
2. **扫描与审计绝对只读**：所有磁盘扫描、应用包透视、启动代理/守护项审计、系统性能采样均严格只读（含隐藏目录、全程 `O_NOFOLLOW` / `AT_SYMLINK_NOFOLLOW` 不跟随符号链接、不跨越挂载卷、**绝不打开或读取任何普通文件内容**）。
3. **清理与操作绝对安全**：
   - 源码、Git 工作树、`.app` 应用本体、正式安装包（`.dmg`/`.pkg`）、文档报告、SSH/GPG/钥匙串凭据与聊天数据全程自动保护，绝不删除。
   - 启动项（`LaunchAgents`/`LaunchDaemons`）与运行中应用仅提供只读透视与 Finder 定位，绝不篡改系统启动配置或强杀用户进程。
   - 仅限个人目录内经规则识别、默认不勾选、用户显式预览确认且二次核验 inode/Git/`lsof` 指纹一致的缓存/日志/窗口状态目录可移入系统废纸篓；禁止永久删除、禁止后台自动清理、禁止自动清空废纸篓。
4. **诚实容量计量**：严格区分已分配块大小与逻辑大小，显式呈现 APFS 克隆共享提示、权限遗漏路径、取消部分状态与外部卷只读锁定。

## 二、UI 视觉与空间几何规范（CleanMyMac 5 1:1 对标）

### 1. 无分割线全画布舞台壳层（Full-Bleed Stage Shell）
- **取消传统分割线**：移除左右直角 `1pt` 分割线与横跨底部的实心状态栏；整个窗口共享同一张随当前模块平滑过渡的双源径向环境光晕画布（`StageBackground`）。
- **内嵌悬浮毛玻璃侧边栏（Floating Inset Glass Sidebar）**：左侧栏采用 `10pt` 外边距内嵌的 `18pt` 大圆角超薄毛玻璃容器（`.ultraThinMaterial` + 顶部高光细描边），营造 CleanMyMac 标志性的悬浮玻璃层质感。
- **居中悬浮发光主控圆球（Floating Action Orb Overlay）**：直径 `64pt`（含 `78pt` 外层呼吸光晕环）的主操作圆球直接悬浮于舞台底部中央，左右两侧配半透明毛玻璃胶囊浮标（左侧：扫描文件数与权限遗漏入口；右侧：APFS 共享容量提示）。

### 2. 侧边栏模块序列（1:1 对齐 CleanMyMac 5 七大核心模块）
1. **顶部入口**：品牌标志 + **智能助手（Assistant）** 实时健康分胶囊。
2. **核心七大模块（官方同序）**：
   - ① **智能护理**（*Smart Care*，`nav-smartcare`，青碧→靛蓝）：一键全维体检，**横向并排五联立式玻璃卡**（一屏免滚动总览：系统清理、安全保护、性能优化、应用管理、空间透镜）。
   - ② **系统清理**（*Cleanup*，`nav-suggestions`，珊瑚粉→魅影紫）：左分类导航 + 右明细勾选双栏审阅台。
   - ③ **安全保护**（*Protection*，`nav-protection`，翡翠青→电光蓝）：只读审计用户/系统启动代理（`LaunchAgents`/`LaunchDaemons`）、下载目录待核验安装包、隐私权限状态与敏感凭据保护防线。
   - ④ **性能优化**（*Performance*，`nav-performance`，薄荷绿→碧波青）：实时内存压力、CPU 与散热、电源、网络吞吐、登录代理概览与前台活跃应用。
   - ⑤ **应用管理**（*Applications*，`nav-applications`，晴空蓝→宝石蓝）：已装应用体积排行、App Store/独立来源标识、关联缓存与卸载残留线索（本体严格只读保护）。
   - ⑥ **我的杂物**（*My Clutter*，`nav-large`，琥珀橙→日落橘）：跨目录大文件与旧文件、纯元数据疑似重复线索、安装包与归档筛查。
   - ⑦ **空间透镜**（*Space Lens*，`nav-overview`，电光蓝→深海蓝）：**全高左右双栏分屏**（左：目录层级树与容量筛选；右：大尺寸交互式比例气泡星图 / 旭日图 / 树状图 / 分栏树 / 占比条 + 底部紧凑检查器）。
3. **实用工具组（*My Tools*）**：**工程洞察**（`nav-projects`）、**文件类型**（`nav-types`）、**占用变化**（`nav-changes`），以及底部挂载卷与快捷扫描网格。

## 三、分阶段渐进实施路线图（Step-by-Step Roadmap）

- **阶段一（本次落地）**：确立 CleanMyMac 1:1 规范，重构内嵌悬浮毛玻璃侧栏、无分割线沉浸舞台与悬浮主控圆球；升级「智能护理」为横向五联立式玻璃卡，升级「空间透镜」为左右分栏全屏气泡视野，并补齐第三大核心模块「安全保护（Protection）」。
- **阶段二（后续迭代）**：深化「系统清理」与云盘空间透视（`~/Library/CloudStorage` 只读占用统计、多语言开发工具缓存细化拆解与按应用分组折叠）。
- **阶段三（后续迭代）**：深化「我的杂物」视觉体验（按文件最后访问/修改双时间轴透视、媒体与归档缩略元信息卡片及快速对比视图）。
- **阶段四（后续迭代）**：深化「性能优化」与菜单栏健康中心（CPU/内存历史微缩波形曲线 Sparkline、后台启动项详情联动与低空间阈值提醒）。
- **阶段五（后续迭代）**：动效与无障碍打磨（模块切换流体过渡、动态减少透明度/减弱动态效果系统辅助功能适配）。
- **阶段六（发布上线）**：版本号定版、Developer ID 签名、Apple 公证装订、Sparkle 升级通道验证与收尾清理。
