# AetherDisk

轻量、紧凑的 macOS 原生磁盘分析工具。Swift 6 + SwiftUI / AppKit，Apple Silicon，macOS 14+。

当前版本为 **0.2.2**，正式包采用 Developer ID 签名、Apple 公证和装订票据。

官网：https://aethernative.com/apps/aetherdisk/
下载：https://github.com/bcblr1993/AetherDisk/releases/latest
更新源：https://aethernative.com/apps/aetherdisk/appcast.xml

正式分发为 Apple Silicon、macOS 14+。源码自行构建的默认产物仍为 ad-hoc 预览包，不能替代正式发行包。

## 功能

- 全目录大文件排行：按磁盘占用或逻辑大小、类型和路径筛选，稀疏文件单独辨认；只查看与定位。
- 文件类型占用汇总：统计所有已读唯一文件，不受目录显示预算影响。
- 自定义保护目录：仍参与统计，禁止清理它、其内容和包含它的缓存父目录，设置保存在本机。
- 原生保存面板导出 CSV 元数据报告，包含类型、保留的目录/大文件和未读取路径；不会上传。
- 权限遗漏可展开具体路径和说明。
- 磁盘容量、可用空间、已分配大小、逻辑大小与文件数量。
- 隐藏目录、逐层扫描、取消、逐步显示已完成的顶层目录。
- 占用排行、搜索、目录详情、Finder 定位、同目录历史变化（包括已移除项目）。
- 明确的缓存建议，以及源码、Git 工作树、安装包、签名归档、凭据和个人数据保护。
- 默认不勾选，先检查占用与目录内容，再显示确认页；仅明确确认才移入系统废纸篓。
- Sparkle 2.10.0 应用内更新入口、手动检查、每日自动检查开关、签名更新基础设施。
- 官网同源蓝紫强调色、浅灰白卡片、细边框、紧凑布局和深浅色外观。

## 运行

```sh
swift test --jobs 4
scripts/build-preview.sh
open outputs/AetherDisk.app
```

命令行扫描不启动 GUI，永远只读：

```sh
swift run aetherdisk-scan ~/Downloads --json /tmp/aetherdisk-downloads.json
```

默认不会扫描，用户选择位置或点击扫描后才开始。访问部分受保护的文件夹时，macOS 可能要求授权；权限不足会标记未读取路径，不会当作零占用或完整扫描。可在系统设置中为应用允许完整磁盘访问。

## 清理边界

1. 仅限个人文件夹内、规则识别的真实缓存目录；外部卷只分析。
2. 源码扩展名、项目清单、Git 元数据/跟踪文件/未被忽略文件、安装包、应用包、xcarchive、签名材料、聊天备份等会阻止整个候选目录清理。
3. 不跟随符号链接，不跨卷。发现权限遗漏则该候选不可清理。
4. 预览和执行均检查进程占用；执行前重新核对 inode、大小、修改时间、变更时间、硬链接数等目录指纹。计划两分钟后失效且只能使用一次。
5. 构建目录要求真实项目文件佐证；受保护的源码/安装包/备份容器内部缓存不清理。Git 校验失败保留文件。
6. 批次先全部校验，再逐项移入系统废纸篓；操作错误立即停止，并报告已完成与失败项。
6. 不会自动清空废纸篓。移入废纸篓通常不会立即释放磁盘空间；实际容量变化另行显示。

这些保护采取保守策略，可能保留本可再生成的依赖源码或测试归档。不是仅根据 `.build`、`build`、`target` 名称整批删除。

## 统计与性能

扫描基于文件元数据，不读取内容。按设备和 inode 对硬链接去重，使用分配块数和逻辑长度分别统计。目录排行最多保留 20,000 个节点，并独立保留按已分配与逻辑大小各前 200 个、至少 1 MiB 的大文件候选，避免为数百万文件建立内存树；深入目录时重新扫描当前范围。

APFS 克隆共享、压缩、稀疏文件和其他卷使目录占用不能直接等同于可回收容量。符号链接不计入目标内容，其他卷不遍历。扫描结果包含取消和权限遗漏状态。权限范围不同的两次扫描，其变化可能不具可比性。

历史记录只保存在 `~/Library/Application Support/AetherDisk/Scans`，不上传。更新由 Sparkle 负责，不发送系统概况；更新网络请求本身仍会到达配置的更新服务。

## 验证

参见 [docs/VERIFICATION.md](docs/VERIFICATION.md)。原生界面在 Tart `macos27` 运行并由实际窗口生成截图。QA 数据为本次创建的独立测试文件，不使用用户真实聊天数据作为展示素材。

扫描结果是动态文件系统的观测值，不是原子快照。目录在遍历期间变化、跨卷和深度限制会标记部分结果；部分扫描不覆盖完整历史。清理仅移入废纸篓，不永久删除；应用无法对不配合文件协调、持续并发改写或刻意伪装成缓存的任意数据作出零风险保证。重要文件可设置整个项目/发布目录保护，清理前退出相关应用。
